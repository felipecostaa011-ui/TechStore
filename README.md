# 🛒 TechStore — Dashboard de Vendas

Dashboard interativo para análise de desempenho comercial de uma loja fictícia de tecnologia, desenvolvido com **HTML, CSS e JavaScript**. O projeto apresenta indicadores e gráficos que ajudam a compreender a evolução das vendas, a rentabilidade e o comportamento comercial.

## 📊 Sobre o projeto

O TechStore foi desenvolvido como um projeto de análise de dados e visualização de informações, com o objetivo de transformar dados de vendas em indicadores que facilitem a interpretação dos resultados e a tomada de decisões.

O dashboard utiliza uma base de dados fictícia com **32.345 pedidos**, abrangendo o período de novembro de 2024 a abril de 2026.

## ✨ Funcionalidades

- **Indicadores de desempenho (KPIs):** receita total, lucro total, margem de lucro, ticket médio e quantidade de pedidos.
- **Evolução mensal:** comparação entre receita e lucro ao longo do tempo.
- **Análise por categoria:** acompanhamento da receita de notebooks, tablets, smartphones, monitores e acessórios.
- **Margem de lucro:** visualização da evolução mensal da rentabilidade.
- **Formas de pagamento:** análise da receita por cartão de crédito, PIX, boleto e cartão de débito.
- **Canais de venda:** comparação entre site próprio, marketplaces e lojas físicas.
- **Análise regional:** distribuição da receita pelas regiões brasileiras.
- **Ranking de produtos:** identificação dos produtos mais vendidos por unidades.
- **Desempenho de vendedores:** ranking dos cinco vendedores com maior receita.
- **Tabela mensal detalhada:** consulta de pedidos, receita, custos, lucro e margem.
- **Filtros interativos:** seleção de períodos de 6 meses, 12 meses ou todo o histórico, além de filtros por categoria.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do dashboard.
- **CSS3:** estilização, layout responsivo, animações e identidade visual.
- **JavaScript:** cálculos, filtros, atualização dos indicadores e interação com os gráficos.
- **Chart.js:** criação e apresentação dos gráficos.
- **Google Fonts (Inter):** tipografia da interface.

## 🚀 Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/felipecostaa011-ui/TechStore.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd TechStore
   ```

3. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar dependências localmente. O dashboard utiliza bibliotecas e fontes carregadas pela internet, portanto, uma conexão ativa é necessária para carregar esses recursos externos.

## 📈 Objetivos de análise

O projeto permite explorar questões como:

- Como a receita e o lucro evoluem ao longo dos meses?
- Quais categorias de produtos geram mais receita?
- Quais canais de venda apresentam maior participação comercial?
- Quais regiões concentram as vendas?
- Quais produtos possuem maior volume de unidades vendidas?
- Como a margem de lucro se comporta ao longo do período analisado?

## 📌 Observação sobre os dados

Os dados utilizados são **fictícios** e foram preparados para fins de demonstração e estudo. Os resultados não representam uma empresa real.
